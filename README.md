# Cricket Pro for Windows

## Which file should I download?

| Your Windows | Download |
|---|---|
| 64-bit (most computers) | `Cricket_Pro_Setup_1.3.5-x64.zip` |
| 32-bit | `Cricket_Pro_Setup_1.3.5-x32.zip` |

Not sure? Open **Settings > System > About** and look at **System type**.

## How to install

1. Download the zip file and **extract it** (right-click the zip > **Extract All**).
2. **First install the Visual C++ Redistributable** from the extracted folder: `VC_redist.x64` (64-bit zip) or `VC_redist.x86` (32-bit zip). Double-click it, accept the license and click **Install**. If it says it is already installed, just close it.
3. **Then install `Cricket Pro Setup 1.3.5`** (the `.exe` in the same folder). Double-click it and follow the steps.
4. Open **Cricket Pro** and log in with your username and password.

A short video guide is also included in the zip.

## Troubleshooting

If you see **"The streaming service could not load (error 3)"**, the Visual C++ Redistributable is not installed. Install it (step 2 above), then restart Cricket Pro.
